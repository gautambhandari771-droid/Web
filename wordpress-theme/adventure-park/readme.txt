The Adventure Park website (Shivpuri, Rishikesh) as a WordPress theme.

== Description ==

The same design, booking form, contact form, UPI payment section, photo galleries,
offline copy and search-engine data as the Adventure Park website, with the details you
change most often in the WordPress dashboard:

* Appearance → Customize → Adventure Park: phone numbers, WhatsApp, email, address,
  map link, Instagram, all prices, the advance percentage, the refund window,
  the UPI ID and QR code, and the activity photos.
* Pages → Home / About / Booking / Contact: a "Page text" box under the editor holds
  each page's headings, introductions, steps, numbers and Google title and description.
  The Home page editor holds the FAQ (one "Details" block per question);
  the About page editor holds the founder's story.
* Appearance → Menus: the main menu (top of every page and the mobile menu).

== Installation ==

1. Appearance → Themes → Add New Theme → Upload Theme, choose adventure-park.zip,
   then Install Now and Activate.
2. The theme creates the Home, About, Booking and Contact pages, sets Home as the
   front page, builds the main menu and switches on readable page addresses
   (/booking/ instead of /?page_id=12). Nothing is created twice.
3. Settings → General: set the Site Title to "Adventure Park Rishikesh".

See the install guide that came with the theme for the full steps.

== Frequently Asked Questions ==

= Can I use an SEO plugin? =

Yes. With Yoast SEO, Rank Math, All in One SEO or SEOPress active, the plugin writes the
titles, descriptions and link previews; the theme keeps adding its structured data
(prices, opening details, FAQ).

= The site does not work with a page builder or "Edit site" =

This is a classic theme: the designed pages come from the theme, and their text is
edited in the "Page text" box and the Customizer. Pages you add yourself use a plain
page layout in the site's style.
